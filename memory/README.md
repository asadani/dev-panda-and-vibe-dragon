# Creative memory

Open this directory as an optional Obsidian vault, or read the Markdown directly. No plugin, private vault, or running Obsidian instance is required. Notes' flat properties define a small graph; `links` contains stable IDs for the Python index. Body wikilinks use actual vault-relative note paths (not IDs) so Obsidian's Graph view resolves them. Standard Markdown links also provide navigation. Links to project artifacts are relative and may need a normal editor when outside an Obsidian vault.

- [Narrative canon](canon.md)
- [Approved production preferences](preferences.md)
- [Creator's reach feedback](reach-feedback.md)
- [Unproven simplification hypothesis](simplification-hypothesis.md)
- Historical comic notes in `history/` link to their original artwork and inspection provenance.

Generated graphs are disposable. Never put credentials here. Dates and performance counts that were not supplied remain unknown. See the skill's memory reference for retrieval and update rules.
