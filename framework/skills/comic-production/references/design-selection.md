# Reference selection and redesign

The current series default is detailed graphite and ink, documented in `series/dev-panda-vibe-dragon.md`. Use the published Tool Addiction and Fairness references identified there. Preserve Panda's complete spectacles and Dragon's mature, wise identity. The earlier Bold Ink sheet is available only as an optional alternative; do not reopen the old A/B decision automatically.

For each episode, record the reference files, canon version and latest explicit requirements in the brief. Copy the chosen reference images into the local episode workspace for reproducibility. The four-panel 2×2 template and original footer are the current defaults.

For a new series or an explicitly requested redesign, generate and present actual candidates before requesting a choice. Compare the same short scene, expressions, relative scale and layout. Save the selection with provenance and version the reference pack. Do not present placeholders or a proposed specification as approved artwork. If generation is unavailable, state the blocker and preserve the specifications.
